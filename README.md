# Quant Research Tools

![Python](https://img.shields.io/badge/Python-3.13-blue)
![License](https://img.shields.io/badge/License-MIT-green)

Open-source quantitative finance utilities for systematic trading, portfolio analytics, and financial research.

---

## Features

### Statistics

- ✅ Drawdown Series
- ✅ Maximum Drawdown
- ✅ Drawdown Duration
- 🚧 Recovery Time

### Planned

- Sharpe Ratio
- Sortino Ratio
- Calmar Ratio
- Profit Factor
- CAGR
- Volatility
- Value at Risk (VaR)
- Conditional VaR
- Beta
- Alpha

---

## Installation

```bash
git clone https://github.com/bilal-ffs/quant-research-tools.git

cd quant-research-tools

pip install -e .
```

---

## Running Tests

```bash
pytest
```
