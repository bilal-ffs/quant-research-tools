# Portfolio Analytics

Benchmark-relative portfolio metrics.

## `beta()`

Measures portfolio sensitivity to benchmark returns.

## `alpha()`

Calculates portfolio alpha relative to a benchmark.

## `active_return()`

Calculates the difference between portfolio and benchmark returns.

## `tracking_error()`

Measures the volatility of active returns.

## `information_ratio()`

Measures active return relative to tracking error.

## `treynor_ratio()`

Measures excess portfolio return relative to systematic risk measured by beta.
