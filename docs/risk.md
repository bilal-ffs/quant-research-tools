# Risk Analytics

Risk and downside measures for return series.

## `volatility()`

Calculates annualized return volatility.

## `downside_deviation()`

Calculates downside deviation relative to a risk-free rate.

## `value_at_risk()`

Calculates historical Value at Risk.

The result is expressed as a positive loss magnitude.

## `conditional_value_at_risk()`

Calculates historical Conditional Value at Risk, also known as Expected Shortfall.

The result is expressed as a positive loss magnitude.

## `ulcer_index()`

Measures drawdown severity using the compounded equity curve.
