# Statistics

Statistical performance and trade analytics.

## Performance Metrics

### `drawdown_series()`

Calculates the drawdown series from periodic returns.

### `max_drawdown()`

Calculates maximum drawdown.

### `drawdown_duration()`

Calculates drawdown duration.

### `cagr()`

Calculates compound annual growth rate.

### `sharpe_ratio()`

Calculates the Sharpe ratio.

### `sortino_ratio()`

Calculates the annualized Sortino ratio.

### `calmar_ratio()`

Calculates the Calmar ratio.

## Trade Analytics

### `profit_factor()`

Calculates profit factor.

### `expectancy()`

Calculates trade expectancy.

### `win_rate()`

Calculates the percentage of winning trades.

### `average_win()`

Calculates average winning trade.

### `average_loss()`

Calculates average losing trade.

### `payoff_ratio()`

Calculates the ratio between average winning and losing trades.
